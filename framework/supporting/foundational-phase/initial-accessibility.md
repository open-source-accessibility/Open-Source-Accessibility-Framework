# Accessibility

Accessibility is a core priority for our project. We want everyone — including people with disabilities and people using assistive technology — to be able to read, navigate, and contribute to this site.

This document will explain our accessibility commitment, how contributors can help us uphold it, and how to report accessibility issues.
