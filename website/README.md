# Open Source Accessibility Framework — website

This is the Vue 3 + Vite application that renders the framework's companion
site, built from the Markdown content in [`framework/`](../framework) and the
root [`README.md`](../README.md).

## Development

```sh
npm install
npm run dev
```

## Type-check, build, and minify for production

```sh
npm run build
```

## Run unit tests

```sh
npm run test:unit
```

## Lint

```sh
npm run lint
```
